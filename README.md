# Retail Sales Performance Analysis

## Overview
This project shows a sample retail sales dataset containing 10,000 records using PostgreSQL.

The objective is to investigate sales performance, customer purchasing behaviour, regional revenue and product performance through SQL analysis.

## Tools
- PostgreSQL
- SQL
- Visual Studio Code

## Dataset
The project uses a sample retail dataset containing information about:
- Orders and order dates
- Customers and regions
- Products and categories
- Units sold and order revenue
- Payment methods and order statuses
- Sales representatives

## Analysis Performed

1. **Data Exploration:** Examining dataset size, date ranges and order statuses.
2. **Sales Performance:** Comparing revenue across regions, products and categories.
3. **Customer Behaviour:** Investigating customer spending, purchase frequency and average order value.
4. **Customer Segmentation:** Classifying customers based on total spending.
5. **Advanced Filtering:** Identifying qualifying high-value customers using multiple conditions and CTEs.

## SQL Concepts Demonstrated
- Filtering and sorting
- Aggregate functions
- GROUP BY and HAVING
- INNER JOIN
- CASE expressions
- Common Table Expressions (CTEs)
- Subqueries
- Date functions
- NULL handling
